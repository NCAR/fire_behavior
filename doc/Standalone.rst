.. _standalone:

=================================
Idealized and Offline Simulations
=================================

The standalone CFBM runs independently of a live atmospheric model. It can be
driven offline by atmospheric fields from a completed WRF simulation or run on
an idealized domain with prescribed atmospheric and surface conditions. The
following sections describe how to build the standalone model and run either
type of simulation.
